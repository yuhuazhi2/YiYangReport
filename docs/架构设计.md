# 取数生成 Excel 报表工具 — 架构设计

## 1. 项目目标

开发一个 Windows 桌面程序，运行于 Win10 / Windows Server 2016 局域网环境，连接服务器上的 **SQL Server 2016**，读取 **用友 U8 V18.0** 后台数据库（财务与业务数据），按 [`2026版新修订企业财务报模板.xls`](2026版新修订企业财务报模板.xls) 的格式，生成 43 张报表（LK01~LK33）。

**核心原则**：
- **绝不修改模板文件**，仅在内存中复制选定的表页，另存为新文件。
- 生成的报表以**一个文件多表页**形式输出。
- 支持"服务器本机运行"与"局域网远程连接"两种部署方式。
- 支持生成后的**数据核对**（勾稽关系、与用友前台/后台比对）。

## 2. 技术选型

| 层面 | 选型 | 理由 |
|------|------|------|
| 语言 | Python 3.11 | 已就绪，生态成熟 |
| GUI | PySide6（Qt） | 跨版本稳定，界面美观，单窗口可容纳多对话框 |
| 数据库 | pyodbc + ODBC Driver 17/13 for SQL Server | 微软官方驱动，支持 SQL Server 2016 |
| Excel（模板/生成） | **win32com (pywin32)** 为主引擎 | 唯一能完整保留 .xls（97-2003）格式、公式、合并单元格、列宽字号的方式 |
| Excel（只读解析） | xlrd | 读取模板结构、定位单元格 |
| 打包 | PyInstaller | 生成 exe 便于局域网分发 |

> 说明：模板为 `.xls` 旧格式，若改用 openpyxl/xlwt 会丢失格式与公式，故生成引擎以 **win32com 驱动本机 Excel** 为准。程序运行环境需安装 Microsoft Excel。

## 5. 关键流程

### 5.1 连接与配置记忆
1. 启动 → 弹出**连接对话框**（服务器、实例、数据库、用户名/密码、或 Windows 集成认证）。
2. 测试连接成功 → 将连接信息（**密码加密存储**）写入 `config/user_config.json`（用户目录）。
3. 下次启动自动填充上次信息，可直接连接。

### 5.2 报表选择
- 连接成功后 → **报表选择对话框**：列出 43 张表（代码 + 名称），默认全选。
- 用户勾选子集 → 只复制生成被选表页。
- 一次性界面：连接 → 选择 → 生成，避免多级嵌套对话。

### 5.3 生成编排（顺序生表 + 共享缓存）
- **按 LK 代码顺序**依次处理（LK01 → LK33），符合勾稽依赖（主表依赖明细表）。
- 每张报表实现 `fetch(context)` 与 `write(sheet, context)`。
- 取数结果写入 **context 缓存**，被后续报表复用，避免重复查询同一张 U8 表。

### 5.4 输出
- 复制模板中选定的页 → 逐页填数 → 另存为 `输出目录/财务报表_YYYYMMDD_HHMMSS.xls`。
- 全程不写回原模板。

## 6. 性能与取数策略（详见 `docs/数据流与取数策略.md`）

- **一次性批量取数**：对同一会计期间，先集中批量查询各 U8 明细表到内存（DataFrame/字典），再供各报表共享。
- **顺序生表**：按 LK 序号生成，进度条可见，避免长时间无响应。
- **连接复用**：单一 pyodbc 连接 + 游标，避免频繁重连。
- **索引意识**：查询条件优先使用 U8 表的期间、科目、cCode 等有索引字段。

## 7. 可核对性设计

- 每张报表记录其**取数 SQL 与结果快照**（写入日志/审计文件）。
- `verify/reconciliation.py` 实现"主要勾稽关系"表中的核对公式。
- 支持导出中间数据，供与用友前台界面、后台表逐项比对。

## 8. 开发阶段

1. **阶段一（本阶段）**：搭建项目骨架、连接、模板解析、引擎、注册表、空报表框架、UI 骨架。
2. **阶段二**：实现 LK01、LK02、LK03 三大主表取数与填列。
3. **阶段三**：实现明细类报表（存货、往来、固定资产等）。
4. **阶段四**：勾稽校验与核对功能。
5. **阶段五**：打包、性能优化、容错。
